# Support the Project

Financial Decision Studio remains free to use under its license (see [`LICENSE`](LICENSE) and [`LICENSING.md`](LICENSING.md)) — support is entirely optional.

## Ways to support

- **Buy Me a Coffee:** [buymeacoffee.com/pietrocorona](https://buymeacoffee.com/pietrocorona).
- **GitHub Sponsors:** not currently active.

## What donations are — and are not

Donations and sponsorships are voluntary support for the continued development of Financial Decision Studio. They:

- help fund continued maintenance and development, and
- are genuinely appreciated.

They do **not**:

- purchase the software,
- unlock any functionality (all functionality in a given release is available to every user under the license),
- grant commercial-use rights, redistribution rights, sublicensing rights, or any right beyond what [`LICENSE`](LICENSE) already grants, or
- create any contractual or support obligation beyond what is described here.

Commercial licensing is a separate matter from donations — see [`COMMERCIAL.md`](COMMERCIAL.md).

## Other ways to help

- Report bugs and calculation discrepancies via [Issues](../../issues) (please read [`SECURITY.md`](SECURITY.md) first if it might be a security issue, and never paste real financial data).
- Suggest improvements via a Feature Request issue.
- Tell other people who might find it useful that it exists.
